# ArchiveLens User Guide (for archivists)

No technical knowledge needed.

## 1. Log in
Click **Archivist login** (top right) and enter the password you were given.

## 2. Add items
1. Go to **Admin**.
2. Click **Choose files**. You can pick many at once: scans (PDF, JPG, PNG, TIFF), text files, or recordings (MP3, WAV, MP4).
3. Optional: type the **Source** (e.g. "Smith family papers") and **Rights** (e.g. "Public domain").
4. Click **Upload & process**.

Each file goes through: reading the text → suggesting a catalogue record → making it searchable.
Watch the **Pipeline status** table: *pending → processing → done*. Most scans take under a minute.

**Bulk option:** Ask your technical contact to copy files into the *watch folder*. They are added automatically.

## 3. Check the catalogue record
Open an item and look at **Review metadata**. The computer fills it in, but you know the collection best.
Correct the title, date, places or tags, then click **Save changes**. Your edits are kept permanently.

## 4. If something fails
A **failed** item shows the reason in red. Common causes: an unsupported file type, a blank or very faint scan,
or a file over 20 MB. Fix the file and upload again, or click **Re-run pipeline**.

## 5. Search and ask
- **Browse & search:** Type words or an idea ("shipwrecks near Cape Race"). Results match meaning, not just exact words.
  Filter by type, tag or years.
- **Ask the Archive:** Ask a question in plain English. The answer only uses items in the archive and lists its
  sources; always open the sources to confirm.

## 6. Duplicates
If you upload a file that is already in the archive, it is skipped and you'll see the existing item number.
